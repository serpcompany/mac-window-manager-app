# Window Manager 1.0.0

The first Mac App Store release candidate for Window Manager.

- Move and resize windows with configurable keyboard shortcuts and drag-to-snap areas.
- Keep Window Manager available from both the Dock and macOS menu bar.
- Ship the SERP identity under the isolated `com.serp.windowmanager` namespace.
- Preserve upstream Rectangle attribution and its MIT license.

Download `Window-Manager-1.0.0.dmg`, open it, and drag Window Manager to Applications. The universal installer is Developer ID signed, notarized by Apple, and supports Intel and Apple silicon Macs.

Window Manager requires macOS Accessibility permission to control other applications' windows. This tag identifies the exact source used for App Store build 3, including the corrected high-contrast icon, storefront presentation, and public-only window identification implementation; GitHub prerelease status tracks Apple review and will be promoted after Apple releases the build.
