# Working visual identity

These tokens are independently authored for the development identity and can be replaced after the owner chooses a final brand.

| Token | Value | Use |
| --- | --- | --- |
| `brand.primary` | `#5B3FE8` | Icon gradient start |
| `brand.secondary` | `#24105F` | Icon gradient end |
| `brand.accent.cyan` | `#8AF3FF` | Active window pane |
| `brand.accent.mint` | `#3DD6B0` | Active window pane gradient |
| `brand.content` | `#FFFFFF` | Window-grid panes |

The four-pane grid communicates window layout without copying Rectangle's half-window icon or three-dot treatment.
